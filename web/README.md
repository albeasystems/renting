# Renting website

Static site for the Renting iPhone app (working name, see `src/site.js`): nine languages (the app's own: es en fr it de pt ar hi zh),
three working tools, prerendered HTML for search engines and AI crawlers. Vite + React 19 + Tailwind v4, the same pipeline as
`amortix/web` and `Capital/web`. Product context in `../PRODUCT.md`.

```
npm install
npm test                  # engine figures against the app, translation parity, copy rules (41 tests)
npm run dev               # http://localhost:5173/renting/
npm run build             # client + SSR bundle + prerender of every page into dist/
node scripts/audit.mjs    # SEO and link audit over dist/
```

## What is where
- `src/site.js`: the undecided facts, each ONE constant: `SITE_NAME` (provisional), `APP_ID` (null until the app is on the App Store:
  the "coming soon" statement becomes the download button, and the JSON-LD, smart banner and llms.txt gain the store URL), `ORIGIN` / `BASE`.
- `src/engine.js`: port of the app's formulas (`ReportService.swift` depreciation and reduction, `Compliance.swift` first month at the new rent).
  `engine.test.js` pins the examples quoted in the copy.
- `src/content/<lang>.js` mirrors `es.js` key for key (`content.test.js` enforces it). Tool pages, tool labels and the legal pages exist in
  Spanish and English only: the rules they explain are Spanish. `{app}` in any string is replaced by `SITE_NAME`.
- `src/seo.js`: head tags, JSON-LD (SoftwareApplication with pre-order availability, WebPage, WebApplication, FAQPage, BreadcrumbList, ItemList),
  hreflang, sitemap, robots, llms.txt and llms-full.txt.
- `public/media/` is generated from `../marketing/` (`node make-gif.mjs`): animated WebP and framed GIF of the journey, single views, the wide
  yearly matrix and the social cards, in every language, plus the icons from the app icon.

## Captures in every language
`sh marketing/capture.sh [es,en,...]` drives the iOS Simulator (Debug build, 'Renting Test' iPhone 17 Pro) with the built-in fictional
portfolio, once per language and per screen, using DEBUG-only launch flags (`-debugDemo`, `-debugPro`, `-debugTab`, `-debugScrollChart`,
`-debugYear`, `-debugReceipt`). The last three live in `DashboardView.swift` and `CollectionsView.swift` inside `#if DEBUG`.
`ONLY="05-year 06-receipt" sh marketing/capture.sh ar` retakes some frames. Then `cd marketing && npm install && node make-gif.mjs`.

## Deploy
The repo is `albeasystems/renting` and `.github/workflows/pages.yml` (same as amortix) runs the tests, builds, audits and publishes
`web/dist/` to GitHub Pages at `https://albeasystems.github.io/renting/` on every push to `main` (Pages > Source = "GitHub Actions").
With a custom domain, build with `VITE_SITE_ORIGIN=https://your.domain BASE_PATH=/` and update `ORIGIN`/`BASE` in `scripts/audit.mjs`.
`marketing/gif/` is not tracked: it is regenerated by `node make-gif.mjs`, and the files the site uses are copied to `web/public/media/`.

## Things to know
- No prices, ratings, testimonials or download counts appear anywhere: none exist. The captures show a fictional portfolio and the page says so.
- The site never states a current IRAV or CPI value: the calculator asks for it, because the index and the caps change often.
- ar / hi / zh copy has not been reviewed by a native speaker. The legal pages are not lawyer-reviewed and exist in es and en only.
- "renting" also means vehicle leasing in Spanish: decide the final name before investing in brand SEO.
- `robots.txt` and `llms.txt` are generated into `dist/`. Crawlers read them at the domain root; on `albeasystems.github.io` that root belongs
  to the `albeasystems.github.io` repository (a custom domain fixes it).
